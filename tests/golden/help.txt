usage: jury [-h] [--pr PR] [--issue ISSUE] [--repo REPO]
            [--diff-file DIFF_FILE] [--commit COMMIT] [--commits COMMITS]
            [--config CONFIG] [--policy POLICY]
            [--context-mode {diff-only,expanded}] [--redact] [--no-redact]
            [--rounds ROUNDS] [--max-rounds MAX_ROUNDS] [--early-stop]
            [--no-early-stop] [--auto] [--no-auto]
            [--total-timeout TOTAL_TIMEOUT] [--phase-timeout PHASE_TIMEOUT]
            [--retries RETRIES] [--max-diff-bytes MAX_DIFF_BYTES] [--chunk]
            [--no-chunk] [--exclude GLOB] [--include GLOB] [--seed SEED]
            [--chair CHAIR] [--mock] [--strict] [--min-vendors N]
            [--no-min-vendors] [--verify] [--no-verify] [--doctor] [--json]
            [--write WRITE] [--effort {low,medium,high}] [-o OUTPUT]
            [--metadata-json PATH]
            [--format {markdown,json,sarif,keel-reviews}]
            [--decision {chair,vote}] [--transcript] [--no-transcript]
            [--verbose] [--live] [--theater] [--no-theater]
            [--theater-style {flat,pixel}] [--post-summary] [--post-inline]
            [--post-progress] [--post-mode {single,phased}] [--dry-run]
            [--label] [--ci] [--fail-on FAIL_ON] [--cache] [--clear-cache]
            [--cache-dir CACHE_DIR] [--suggest-patches] [--patches-out PATH]
            [--incremental] [-q] [--config-validate] [--strict-config]
            [--tiered] [--hints] [--version]

Cross-vendor multi-agent PR review jury.

options:
  -h, --help            show this help message and exit
  --config CONFIG       path to jury.toml (default: ./jury.toml or built-in)
  --policy POLICY       path to an optional repository review policy file
                        (default: auto-discover .jury/policy.toml or jury-
                        policy.toml); missing policy files are allowed
  --context-mode {diff-only,expanded}
                        context policy: diff-only sends only the diff;
                        expanded includes PR context
  --redact              redact secrets from prompt text before sending
                        (default: from config)
  --no-redact           do not redact secrets before sending
  --rounds ROUNDS       override number of rounds (1=review, 2=+debate); a
                        fixed value disables early-stop for reproducible
                        benchmarking
  --max-rounds MAX_ROUNDS
                        ceiling on adaptive rounds when early-stop is on
  --early-stop          stop after round 1 when reviewers agree; debate only
                        on disagreement
  --no-early-stop       disable adaptive early-stop (honour a fixed number of
                        rounds)
  --auto                risk-aware auto-depth: scale rounds/verify to the diff
  --no-auto             disable auto-depth (use configured/fixed rounds)
  --total-timeout TOTAL_TIMEOUT
                        overall wall-clock budget (seconds) for the whole run
  --phase-timeout PHASE_TIMEOUT
                        per-phase wall-clock budget (seconds)
  --retries RETRIES     extra attempts for transient (timeout/rate-
                        limit/spawn) failures
  --max-diff-bytes MAX_DIFF_BYTES
                        size budget for the (filtered) diff before
                        chunking/too-large
  --chunk               chunk an over-budget diff by file instead of failing
  --no-chunk            disable diff chunking (fail clearly when over budget)
  --exclude GLOB        exclude files matching this path glob (repeatable)
  --include GLOB        only review files matching this path glob (repeatable)
  --seed SEED           run seed for reproducible orchestration; mock runs
                        with the same seed produce byte-identical reports
                        (overrides [jury] seed)
  --chair CHAIR         override the synthesizing chair agent
  --mock                offline demo: use deterministic mock agents
  --strict              fail if any configured agent CLI is missing
  --min-vendors N       fail (exit 3) unless at least N distinct vendors
                        contributed a review; 0 disables. Default from config
                        ([jury.ci] min_vendors, shipped as 2). --strict checks
                        availability at startup, this checks participation at
                        the end
  --no-min-vendors      opt out of the cross-vendor guard: accept a run whose
                        panel collapsed to a single vendor (same as --min-
                        vendors 0)
  --verify              run the verification round (default: from config)
  --no-verify           skip the verification round
  --doctor              print a local readiness diagnostics report and exit
                        (no telemetry is collected or sent)
  --json                with --doctor, print the machine-readable provider
                        export (schema ai-jury.doctor.v1) as the only thing on
                        stdout
  --write WRITE         with --doctor, also write the diagnostics as JSON to
                        this path (secrets redacted)
  --effort {low,medium,high}
                        reasoning effort for every agent this run (overrides
                        [[agent]] effort); ignored with a warning for agents
                        whose vendor has no effort control
  -o, --output OUTPUT   write the report to a file instead of stdout
  --metadata-json PATH  write machine-readable run metadata (durations,
                        status, rounds) as JSON
  --format {markdown,json,sarif,keel-reviews}
                        output format for stdout/--output (default: markdown);
                        'keel-reviews' emits one review record per panelist
                        plus the chair
  --decision {chair,vote}
                        final verdict: 'chair' synthesis (default) or panel
                        'vote' (tally the reviewers); overrides [jury]
                        decision
  --transcript          render the full play-by-play transcript (each agent's
                        review, the debate, and the chair's reasoning) instead
                        of the summary report
  --no-transcript       force the summary report even if [jury] transcript is
                        set
  --verbose             summary report followed by the full transcript, in one
                        document
  --live                stream each step (review, debate, verdict) to stdout
                        as it happens; add --pr --post to also post each step
                        as its own PR comment
  --theater             animated deliberation view of the live run (each model
                        seated around a table, speaking per phase, panel-
                        vote/chair finale); needs an interactive terminal,
                        else falls back to --live. Can be defaulted on in
                        jury.toml ([jury] theater = true)
  --no-theater          disable the theater scene even if jury.toml enables it
  --theater-style {flat,pixel}
                        --theater scene style: 'flat' (ANSI line scene,
                        default) or 'pixel' (pixel-art room; needs a
                        truecolor+unicode terminal). Defaults from jury.toml
                        ([jury] theater_style)
  --post-summary, --post
                        post the report as a single summary comment on --pr
  --post-inline         post inline review comments for located findings on
                        --pr
  --post-progress       keep a live, sticky status comment on --pr updated per
                        round/chunk
  --post-mode {single,phased}
                        with --post-summary: 'single' (one comment) or
                        'phased' (separate Round 1 / debate / decision
                        comments)
  --dry-run             with --post-inline, print what would be posted without
                        calling GitHub
  --label               apply classification labels (review effort / risk /
                        security) to --pr (off by default; never applied
                        automatically)
  --ci                  CI mode: exit non-zero when blocking findings remain
  --fail-on FAIL_ON     comma-separated severities that fail CI (overrides
                        config)
  --cache               use the local result cache: reuse a cached outcome for
                        an unchanged diff+config, else run and store it (off
                        by default)
  --clear-cache         delete all local cache entries and exit (also: `jury
                        cache clear`)
  --cache-dir CACHE_DIR
                        override the cache directory (default: $JURY_CACHE_DIR
                        or ~/.cache/ai-jury)
  --suggest-patches     emit a separate, opt-in suggested-patches section for
                        VERIFIED findings (read-only; never applied
                        automatically)
  --patches-out PATH    with --suggest-patches, write the patches to this file
                        instead of appending them after the report
  --incremental         review only the diff since the last jury run on --pr
                        when a prior marker exists, else fall back to a full
                        review
  -q, --quiet           suppress progress logs on stderr
  --config-validate     validate the resolved config and exit (0 valid, 2
                        invalid)
  --strict-config       treat configuration warnings as errors
  --tiered              opt-in risk-aware tiered model routing with frontier
                        anchor (issue #524)
  --hints               run local static analysis pre-pass (Ruff/ESLint) to
                        inject hints (issue #523)
  --version             show program's version number and exit

input:
  --pr PR               GitHub PR number/URL to review (uses `gh`)
  --issue ISSUE         GitHub issue number/URL to review for
                        completeness/clarity (uses `gh`); runs the full jury
                        with an issue-quality rubric
  --repo REPO           owner/name for --pr/--issue (defaults to current repo)
  --diff-file DIFF_FILE
                        path to a diff file, or '-' for stdin
  --commit COMMIT       review the diff one commit introduces (needs a git
                        repo)
  --commits COMMITS     review a commit range, e.g. origin/main..HEAD or
                        HEAD~5..HEAD (needs a git repo)

Subcommands (each takes its own --help): init, config, comment, apply, replay,
run-agent, cache clear, examples, guide.
