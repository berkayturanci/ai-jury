🏛️ agent-review-council GitHub

Install once. Run a cross-vendor review council anywhere.

A small, stdlib-only Python CLI that drives each vendor's native coding-agent CLI — Claude Code, OpenAI Codex, Google Antigravity — plus an optional free, offline local / open-weight model, to review the same diff or PR, cross-examine each other, and synthesize one chair verdict. Local-first. Not API calls.

Why a native-CLI council

Different models miss different things. Running them as an adversarial panel — each seeing the others' findings and arguing — surfaces more real issues and filters more false positives than any single reviewer. The research-backed lever is vendor heterogeneity, not more rounds. Each reviewer runs in its own native CLI with its own tooling and context, rather than as a raw model API call.

Quickstart

pipx install agent-review-council

council init                                      # scaffold council.toml (detects agents + local models)
council --pr 123                                  # review a GitHub PR
git diff origin/HEAD... | council --diff-file -   # review the current branch
council --ci --fail-on high,critical              # gate CI on blocking findings
council --mock --diff-file examples/sample.diff   # offline demo, no live CLIs

Requires Python 3.11+ and at least one reviewer — an agent CLI (claude, codex, agy) or a free, offline local model via Ollama; missing/unreachable ones are skipped. gh is needed for --pr.

How it works

  1. Round 1 — independent review. Every available agent reviews the diff concurrently with the same rubric.
  2. Round 2 — debate. Each agent sees the others' reviews and emits agree / dispute / missed.
  3. Verification. A tool-equipped agent re-reads the code per finding to drop false positives.
  4. Synthesis. The chair consolidates into one verdict plus consensus, disputed, and single-reviewer findings.

Free & offline option

Add a local open-weight model (Ollama, llama.cpp, vLLM, LM Studio) as a panel seat — zero cloud cost, fully offline, or mixed with cloud CLIs for more diversity. Local reviewer →

Local-first & private

diff-only context by default; secret redaction on; reviewers run sandboxed/read-only. No source outside the diff, no repo history, no env vars are sent. Security & data-flow →

Fits your workflow

Drop-in skill

Install as a Claude Code plugin or copy the skill into .claude/skills/. Platform support →

Not a hosted SaaS. This is a local-first CLI + skill, not a hosted review service or a general multi-agent framework. It reviews and reports; it can emit inspectable suggested patches for verified findings, but never applies them automatically.
