# Support Policy

## Questions

For general questions, setup help, or workflow design discussion, use GitHub
Discussions when they are enabled for the repository.

## Bugs and Feature Requests

Use GitHub Issues for actionable bug reports and feature requests. Please include the
command you ran, your Python version, the available agent CLIs, and whether `--mock`
reproduces the issue.

## Security

Do not report security vulnerabilities in public issues. Follow the
[Security Policy](SECURITY.md) instead.
